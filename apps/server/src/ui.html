Du har PDF-investeringsteser per aktie. Nästa steg är att lägga till en endpoint som tar PDF, kör text-extraktion, och sparar som tes knutet till ticker.

Tips: Om du får 401 så kräver servern Basic Auth (APP_USER/APP_PASSWORD).
